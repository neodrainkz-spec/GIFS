# GIFS — архив передачи проекта другому ИИ

**Это специальная ветка передачи**, созданная потому, что скачивание ZIP из ChatGPT у владельца не работало.

Начните с [handoff/START_HERE.md](handoff/START_HERE.md), затем прочтите [главную концепцию](handoff/PROJECT_CONCEPT.md), [техническую карту](handoff/TECHNICAL_MAP.md), [ошибки и QA](handoff/BUGS_AND_QA.md), [ресурсы и историю](handoff/ASSETS_AND_HISTORY.md), [готовое задание ИИ](handoff/AI_TAKEOVER_PROMPT.md).

**Базовая версия для локальной доработки:** [ready/](ready/) (4 яблока + 3 ссылки на услуги). Семияблочная [v13/](v13/) — отклонённый эксперимент; корневой index.html — историческая версия. Реальные опубликованные изображения и шрифты находятся в [assets/](assets/). Содержимое ветки — исходники + документация, но не байтовая копия предыдущего 9,9-МБ ZIP со скриншотами и локальными экспериментами. Читайте ограничения в START_HERE.

Публичный сайт для просмотра: https://neodrainkz-spec.github.io/GIFS/ready/ . Изменение только этой ветки не затрагивает продакшен.
