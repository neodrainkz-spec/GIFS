# GIFS — интерактивная студия

Статический сайт GIFS. Главная страница — `index.html`; остальные страницы, стили, сценарии и изображения находятся в корне проекта и папке `assets`.

- Главная — интерактивная сцена с большим деревом на фоне Алматы и Заилийского Алатау. Четыре яблока ведут в основные разделы.
- «Атмосфера» — отдельная визуальная история с прокруткой и сменой сцен.
- `services.html`, `neodrain.html`, `contact.html` — остальные основные разделы.
- Актуальный hero загружается из `assets/hero-data/` через `hero-loader.js`; это изображение дерева, выбранное для главной страницы.

## Публикация

Сайт публикуется GitHub Pages из ветки `gh-pages`.

Публичный адрес: `https://neodrainkz-spec.github.io/GIFS/`

Источники изображений указаны на странице `credits.html`.
