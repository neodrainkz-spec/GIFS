# GIFS — интерактивная digital-студия

Статический сайт GIFS. Главная страница — `index.html`; основные разделы — `services.html`, `atmosphere.html`, `neodrain.html`, `contact.html`. Источники изображений: `credits.html`.

## Главный экран

- Фото Алматы и яблони загружаются напрямую через `<picture>`: `assets/gifs-hero-v3-desktop.jpg` (1672 × 941) и `assets/gifs-hero-v3-mobile.jpg` (940 × 1672). Не собирайте hero из `assets/hero-data/`: `hero-loader.js` не подключён.
- `home-v3.css` отвечает только за главную страницу; `orchard.css` содержит общие и внутренние стили.
- `orchard.js` размещает четыре интерактивных яблока по нормализованным координатам **исходного фото** с учётом `object-fit: cover`, обрезки, шапки и подвала. В CSS остаётся доступный запасной вариант расположения на случай отключения JavaScript.
- Яблоки поддерживают клавиатурную навигацию, плавное падение и переход; для `prefers-reduced-motion` переход без анимации.

## Публикация

Публичный адрес: https://neodrainkz-spec.github.io/GIFS/

GitHub Pages читает ветку `gh-pages`. При публикации обновляйте её **вместе с** `main`, чтобы версия, которую редактируют, совпадала с опубликованной. Не объявляйте работу законченной до проверки открытой страницы после обновления Pages.
