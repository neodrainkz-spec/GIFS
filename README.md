# GIFS — интерактивная студия

Статический сайт: откройте `index.html` для просмотра. Исходные страницы, стили, сценарии и изображения находятся в корне проекта и папке `assets`.

- Главная — интерактивная яблоня. Четыре яблока ведут в разделы; при выборе яблоко падает и открывает страницу. При уменьшенном движении переход происходит сразу.
- «Атмосфера» — четыре главы с прокруткой от классики до киберпанка, сменой текста, цвета и летательных аппаратов.
- `services.html`, `neodrain.html`, `contact.html` — остальные разделы.

Папка `dist` — копия файлов сайта для публикации. После правок исходных файлов обновите соответствующие файлы в `dist` перед повторной публикацией.

Источники дерева и яблок указаны на странице `credits.html`. Летательные аппараты перенесены из прежней подборки проекта. Новые платные изображения и сервисы не используются.
